Chemistry Teacher Assistant

### Description
```
ChemClass is a comprehensive classroom management app designed for chemistry teachers.

FEATURES

📊 Gradebook
• Enter 2 written exams, 1 oral, 2 performance, and 2 project grades
• Automatic semester grade calculation using the official MEB formula
• Student achievement levels (Excellent / Good / Average / Passing / Failing)
• Year-end grade calculation

🔬 Item Analysis
• Question-level exam analysis
• Difficulty index (p) and discrimination index (d) calculation
• Upper 27% – Lower 27% method analysis
• Level assessment for each question (Easy / Medium / Hard / Very Hard)

👨‍🎓 Student Management
• Add, edit, and delete students
• Observation notes for each student
• Photo attachment

📅 Schedule
• Weekly class schedule creation
• Time slot and classroom info

📝 Lesson Plans
• Objective-based lesson plan creation
• Date and description entry

ChemClass securely stores all your data in the cloud, accessible from any device with an internet connection.
```
